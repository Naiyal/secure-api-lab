# Secure REST API with CI/CD

## Описание проекта
Защищенный REST API на Python/Flask с интеграцией в CI/CD для автоматической проверки безопасности.

## API Endpoints

| Метод | URL | Описание | Требует аутентификации |
|-------|-----|----------|------------------------|
| POST | `/auth/register` | Регистрация нового пользователя | Нет |
| POST | `/auth/login` | Аутентификация и получение JWT | Нет |
| GET | `/api/data` | Получение защищенных данных | Да (JWT) |

## Реализованные меры защиты

### 1. Защита от SQL Injection (SQLi)
- Использование **ORM (SQLAlchemy)** вместо конкатенации строк в SQL-запросах.
- Все запросы к базе данных выполняются через параметризованные методы ORM.

### 2. Защита от XSS
- Все ответы API возвращаются в формате JSON (`jsonify`), который автоматически экранирует HTML-символы.

### 3. Защита от Broken Authentication
- **Хэширование паролей** с помощью `bcrypt` (алгоритм с солью).
- **JWT-токены** для аутентификации с ограниченным временем жизни (1 час).
- **Middleware** (`@jwt_required()`) проверяет токен на всех защищенных эндпоинтах.
